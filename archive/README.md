# Archive

This directory keeps unpublished source that may be useful for future site work. Nothing here is
copied into the built site.

- `themes/inactive-skins/` preserves four retired skin stylesheets and their historical registry
  metadata.
- `themes/prototypes/` preserves the migration's visual explorations and layout studies.
- `themes/structural-example/` preserves the reusable authoring proof formerly used by the test
  harness.
- `posts/` holds planned, unpublished post drafts, including the AI job-market research bundle and
  its weekly data refresh tooling.
- `todo.md` records deferred site work.

Treat these files as references. Reintroducing an item means adapting it to the current contracts
documented in `src/themes/README.md` and the current content approval policy in `CLAUDE.md`.
