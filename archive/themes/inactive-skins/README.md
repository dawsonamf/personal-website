# Inactive skins

These complete stylesheets were removed from `public/` because the current theme registry does not
expose them. Their original registry metadata is preserved in `registry-metadata.md`, sourced from
`js/theme-bootstrap.js` at commit `0f196d094ad64383ec58df5472fc12d403f846b3`.

To reactivate one, translate its metadata into the current typed registry, add an approved picker
label, and audit the stylesheet against the current canonical DOM and theme contracts. The archived
CSS is reference source and is not production-ready by default.
