# Theme prototypes

These standalone HTML files preserve theme and layout experiments. They are historical references,
not inputs to the active theme engine.

From the repository root, preview them with:

```bash
python3 -m http.server 8766 --bind 127.0.0.1
```

Then open `http://127.0.0.1:8766/archive/themes/prototypes/` and select a prototype file. The pages
load tracked media from `public/resources/`; some typography and animation libraries still load from
their original external CDNs.
